Системный VPN / SOCKS5 Режим

Хотите пустить весь трафик Windows / Telegram / Chrome через этот туннель? Запустите локальный скрипт-мост socks-bridge.py. Он подключится к этой вкладке через WebSocket и поднимет локальный SOCKS5 на 127.0.0.1:1080.
