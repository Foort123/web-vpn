# AmneziaWG Config Portal on GitHub Pages

Веб-портал на **GitHub Pages**, являющийся готовым, валидным и рабочим VPN-конфигом для приложения **Amnezia VPN** (с протоколом **AmneziaWG** / Cloudflare WARP).

---

## 🌐 Рабочий сайт
👉 **[https://foort123.github.io/web-vpn/](https://foort123.github.io/web-vpn/)**

Прямой файл конфигурации:  
👉 **[https://foort123.github.io/web-vpn/warp.conf](https://foort123.github.io/web-vpn/warp.conf)**

---

## ⚡ Особенности
- **Рабочий аккаунт Cloudflare WARP:** зарегистрирован и привязан к публичной сети.
- **Обход блокировок (DPI Bypass):** содержит параметры AmneziaWG (`Jc`, `Jmin`, `Jmax`, `H1`, `H2`, `H3`, `H4`) для преодоления блокировок WireGuard.
- **Чистые эндпоинты Cloudflare:** выбор рабочих IP-адресов (`162.159.192.1`, `188.114.96.1` и др.), которые не заблокированы провайдерами.
- **QR-код для смартфонов:** прямое сканирование камерой через приложение Amnezia на iOS / Android.
- **Кнопка в 1 клик:** мгновенное копирование в буфер обмена для ПК (Windows / macOS / Linux).

---

## 📖 Как использовать в Amnezia VPN

1. Откройте сайт [https://foort123.github.io/web-vpn/](https://foort123.github.io/web-vpn/).
2. Нажмите **«Скопировать для Amnezia»** (или отсканируйте QR-код в мобильном приложении).
3. В приложении Amnezia:
   * Нажмите **«Добавить туннель»** ➔ **«Файл с настройками или ключ»**.
   * Вставьте скопированный текст и нажмите **«Подключиться»**.
