# GitHub Pages P2P WebRTC VPN / Proxy

Полноценный децентрализованный туннель, развёрнутый на **100% статическом хостинге GitHub Pages** без выделенного сервера.

---

## 🚀 Как развернуть на своём GitHub Pages за 2 минуты

1. Создайте новый публичный репозиторий на GitHub (например, `gh-vpn`).
2. Загрузите файлы этого проекта:
   - `index.html`
   - `style.css`
   - `app.js`
3. Перейдите в **Settings** репозитория -> вкладка **Pages** (слева).
4. В разделе **Build and deployment**:
   - Source: `Deploy from a branch`
   - Branch: `main` (или `master`), папка `/ (root)`
   - Нажмите **Save**.
5. Через 30 секунд ваш личный туннель доступен по адресу:
   `https://<ваш-юзернейм>.github.io/<имя-репозитория>/`

## 🛠 Как пользоваться

### Шаг 1. Запуск Выходного узла (Exit Node)
1. Откройте ссылку на любом устройстве с **открытым/незаблокированным интернетом** (например: за рубежом, домашний ПК или телефон через другую сеть).
2. Выберите режим **«Выходной узел (Exit Node)»**.
3. Скопируйте сгенерированный **Peer ID** (например, `abc-123-def`).

### Шаг 2. Подключение Клиента (Client)
1. Откройте ту же ссылку на устройстве, где нужно обойти ограничения.
2. Вставьте скопированный **Exit Node ID** в поле ввода.
3. Нажмите **«Подключиться»**.
4. Соединение установится напрямую браузер-в-браузер через **WebRTC SCTP DataChannel** (DTLS шифрование).
5. Теперь вводите любой URL (например, проверьте ваш IP через `https://api.ipify.org?format=json`) и нажимайте **«Перейти»** — трафик пойдёт через удалённое устройство!

## ⚡ Особенности архитектуры
- **0 серверов и баз данных:** хостинг не выполняет никакого серверного кода.
- **Шифрование DTLS/SCTP:** весь трафик между нодами зашифрован аппаратно средствами браузера.
- **Обход NAT:** используются открытые Google STUN-серверы (`stun.l.google.com:19302`).
- **Невозможно заблокировать:** хостинг находится на официальном домене `github.io`.
